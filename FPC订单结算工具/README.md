# FPC 订单结算网页小工具

一个**零依赖、可离线运行**的单文件结算单工具，用于 FPC（柔性电路板）订单的明细录入、税费汇总、A4 打印与 CSV 导出。双击即可在浏览器中使用，无需联网、无需安装任何运行环境、无需后端服务。

## 工具简介

- **纯前端单文件**：`index.html` 内联全部样式与脚本（原生 JavaScript ES2020+），不引用任何外部 CDN、字体、图片或脚本。
- **离线可用**：所有计算与导出均在本地浏览器完成，数据不上传任何服务器。
- **面向场景**：FPC / PCB 打样、小批量订单的临时结算单制作；适合单人快速出单，无需登录或账号体系。
- **视觉规范**：主色沉稳蓝 `#2C6ED5`；图标全部为内联 SVG 线性描边（无 emoji）；颜色统一通过 `:root` CSS 变量定义，便于二次配色。

## 功能说明

### 1. 订单明细录入

- 点击「新增一行」动态添加条目，每行包含三个字段：**条目名称 / 单价（元）/ 数量**。
- 每行小计自动计算（`小计 = 单价 × 数量`），实时显示在行尾。
- 鼠标悬停每行右侧的删除按钮（垃圾桶图标）可移除该行。

### 2. 税费及总价汇总

- 顶部「税率（%）」默认 **13%**，可在 `0–100` 之间修改（步进 0.01），所有行即时重算。
- 「运费（元）」默认 0，可选填写，并入应付合计但**不参与应税基数**。
- 汇总逻辑：

  | 项 | 公式 |
  |----|------|
  | 应税基数 | 所有有效行小计之和（不含运费） |
  | 税额 | 应税基数 × 税率 |
  | 应付合计 | 应税基数 + 税额 + 运费 |

- 金额统一保留两位小数（四舍五入），避免浮点误差。

### 3. 浏览器打印 A4 结算单

- 点击「打印结算单」按钮，或按 `Ctrl / Cmd + P`。
- 打印样式（`@media print`）会**自动隐藏录入控件、按钮与工具栏**，只输出结算单预览（表头 + 明细 + 汇总）。
- 建议在打印对话框中选择「A4」纸张、勾选「背景图形」（如需保留边框与底色）。

### 4. 导出 CSV

- 点击「导出 CSV」按钮，浏览器下载 `FPC结算单_<单据编号>.csv`。
- CSV 带 **UTF-8 BOM** 与 **CRLF 换行**，可直接用 Excel 双击打开，中文不乱码。
- 详细字段格式见「参数与输入输出格式」。

### 5. 草稿暂存（可选）

- 每次录入自动存入浏览器 `localStorage`（键名 `fpc_draft_v1`），关闭页面后重开会自动恢复。
- 点击「清空」可清除全部明细与参数（含草稿），会弹出确认框。
- 单据编号（`docNo`）随草稿一起恢复，保证同一单据多次编辑编号一致。

## 安装与配置

本工具**无需安装、无需配置运行环境**，只有一种「部署」方式：

1. 将 `FPC订单结算工具/` 目录整体保留（不要只复制 `index.html` 单个文件——虽然它也能独立运行，但整体保留便于后续更新与追溯）。
2. 双击 `index.html`，文件会在系统默认浏览器打开（推荐 Chrome / Edge / Firefox 新版）。

> 可选：若希望固定使用某浏览器打开，右键 `index.html` →「打开方式」→ 选择目标浏览器并设为默认。
>
> 可选：将目录放入任意静态文件服务（如 `python -m http.server`）后通过 `http://` 访问；此时 `localStorage` 在所有现代浏览器中均可正常启用（`file://` 协议下部分浏览器会禁用 `localStorage`，草稿功能自动失效但不影响其他功能）。

**没有需要修改的配置文件。** 税率、运费、明细均为运行时输入，不依赖任何外部配置或环境变量。

## 使用方式

### 快速开始

1. 进入本文件夹，双击 `index.html`。
2. 左侧「结算参数」填写税率与运费（默认 13% / 0）。
3. 在明细区逐行录入「条目名称 / 单价 / 数量」，点「新增一行」可加更多条目。
4. 右侧实时显示应税基数、税额、应付合计。
5. 需要留存时点「导出 CSV」或「打印结算单」。

### 示例：制作一张含运费的结算单

| 步骤 | 操作 | 结果 |
|------|------|------|
| 1 | 税率填 `13`，运费填 `20` | 参数生效 |
| 2 | 新增一行：条目 `FPC打样-10x10cm`，单价 `80`，数量 `5` | 小计 `400.00` |
| 3 | 新增一行：条目 `钢网`，单价 `30`，数量 `2` | 小计 `60.00` |
| 4 | 查看右侧汇总 | 应税基数 `460.00`，税额 `59.80`，应付合计 `539.80` |
| 5 | 点「导出 CSV」 | 下载 `FPC结算单_FPC<日期>-<随机>.csv` |

### 修改税率

在「结算参数」的「税率（%）」输入框直接改数字：`0` = 免税、`6` = 低税率、`13` = 默认增值税率。修改后合计立即更新，无需保存或刷新。

## 参数与输入输出格式

### 输入参数

| 参数 | 控件 | 类型 / 范围 | 默认值 | 说明 |
|------|------|-------------|--------|------|
| 税率（%） | 数字输入框 | 0–100，步进 0.01 | 13 | 负数按 0 处理 |
| 运费（元） | 数字输入框 | ≥ 0，步进 0.01 | 0 | 负数按 0 处理；不计入应税基数 |
| 条目名称 | 文本输入框（每行） | 任意字符串 | 空 | 空名称仍参与计算 |
| 单价（元） | 数字输入框（每行） | > 0（否则该行标红不参与合计） | 空 | 非数字 / ≤0 / 空 → 该行无效 |
| 数量 | 数字输入框（每行） | > 0（否则该行标红不参与合计） | 空 | 非数字 / ≤0 / 空 → 该行无效 |

### 输出：CSV 文件格式

文件名：`FPC结算单_<docNo>.csv`（`docNo` 形如 `FPC20260825-A3F9`）。
编码：UTF-8 with BOM；换行：`\r\n`（CRLF）；字段含逗号/引号/换行时自动加引号转义。

内容按行组织为三块：

```
FPC 订单结算单
单据编号,<docNo>
开票日期,<YYYY-MM-DD>
税率(%),<税率>
运费(元),<运费>

条目名称,单价(元),数量,小计(元)
<名称1>,<单价1>,<数量1>,<小计1>
<名称2>,<单价2>,<数量2>,<小计2>
...

应税基数(元),<应税基数>
税额(元),<税额>
应付合计(元),<应付合计>
```

字段说明：

| 行 | 含义 |
|----|------|
| `单据编号` | 自动生成的 `FPC` + 年月日 + `-` + 随机串，每次打开页面生成一次，随草稿恢复 |
| `开票日期` | 当前系统日期 `YYYY-MM-DD`（导出时实时取） |
| `税率(%)` / `运费(元)` | 来自结算参数 |
| 明细表 | 每行一条目，小计 = 单价 × 数量 |
| `应税基数(元)` | 所有有效行小计之和（不含运费） |
| `税额(元)` | 应税基数 × 税率 |
| `应付合计(元)` | 应税基数 + 税额 + 运费 |

### 输出：打印 / 屏幕结算单

与 CSV 同源数据，仅隐藏录入控件后输出为 A4 页面，可供纸质留存或另存为 PDF。

### 本地存储

| 项 | 值 |
|----|----|
| 存储位置 | 浏览器 `localStorage` |
| 键名 | `fpc_draft_v1` |
| 内容 | JSON：明细行、税率、运费、单据编号 |
| 生命周期 | 直到用户点「清空」或手动清除浏览器数据 |

## 校验规则

- 单价或数量为空、非数字、或 ≤ 0 时，该行标红并**不参与合计**，同时显示提示文字。
- 数量与单价做了非负与除零保护；税率 / 运费为负时按 0 处理。
- 导出 CSV 前若**没有有效明细行**，弹出提示「没有有效明细行，无法导出」，不会生成空文件。

## 注意事项

### 安全与隐私

- **数据完全本地**：所有录入、计算、导出均在浏览器本地完成，不连接任何服务器，不上传任何信息。
- **草稿仅存本机**：`localStorage` 数据绑定当前浏览器与当前域名（`file://` 或 `http://` 来源），不会跨浏览器或跨设备同步。在公用电脑使用后，建议点「清空」并清除浏览器站点数据。

### 功能边界与已知限制

- **草稿依赖浏览器存储**：`file://` 协议下部分浏览器禁用 `localStorage`，此时草稿自动失效，但录入与导出功能不受影响。
- **不支持多人协同与云端同步**：适合单人快速结算，不适合作为团队共享账本。
- **无持久账套**：每次打开是新会话（除非有草稿恢复），不自动累计历史单据。
- **打印排版以主流桌面浏览器为准**：移动端浏览器打印建议先「导出 CSV」，在桌面端处理。
- **金额精度**：内部保留两位小数四舍五入，极高精度财务对账场景请以导出 CSV 数值为准，不与银行/税务系统直接比对。

## 常见问题

**Q：双击打不开 / 打开是代码而不是界面？**
A：说明被系统用文本编辑器关联了。右键 `index.html` →「打开方式」→ 选择 Chrome / Edge / Firefox。

**Q：为什么刷新后我填的内容没了？**
A：可能是在 `file://` 协议下浏览器禁用了 `localStorage`。改用 `python -m http.server` 起本地服务再用 `http://` 访问，草稿即可正常保存；或直接用「导出 CSV」留存。

**Q：税率改了但合计没变？**
A：请确认输入的是数字且未超出 0–100；若输入被浏览器拦截为非数字，程序会按 0 处理（免税）。

**Q：导出的 CSV 在 Excel 里中文乱码？**
A：正常情况下不会——文件已带 UTF-8 BOM。若仍乱码，多为用非 Excel 工具以错误编码打开，请用 Excel 双击打开，或导入时指定 UTF-8。

**Q：能多人同时编辑同一张单吗？**
A：不能。本工具为单机本地工具，无后端与协同能力。
