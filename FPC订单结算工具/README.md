# FPC 订单结算网页小工具

一个**零依赖、可离线运行**的单文件结算单工具，用于 FPC（柔性电路板）订单的明细录入、税费汇总、A4 打印与 CSV 导出。双击即可在浏览器中使用，无需联网、无需安装任何环境。

## 快速开始

1. 进入本文件夹，双击 `index.html`。
2. 文件会在系统默认浏览器中打开（推荐 Chrome / Edge / Firefox 新版）。
3. 左侧录入明细，右侧实时显示结算单汇总。

> 所有数据仅保存在你本机浏览器中（可选草稿），不会上传到任何服务器。

## 功能说明

### 1. 订单明细录入
- 点击「新增一行」动态添加条目，每行包含：**条目名称 / 单价（元）/ 数量**。
- 每行小计自动计算（小计 = 单价 × 数量）。
- 鼠标悬停每行右侧的删除按钮可移除该行。

### 2. 税费及总价汇总
- 顶部「税率（%）」默认 **13%**，可直接修改为任意 0–100 之间的数值，所有行即时重算。
- 「运费（元）」默认 0，可选填写，会并入应付合计但不参与应税基数。
- 汇总逻辑：
  - 应税基数 = 所有有效行小计之和（不含运费）
  - 税额 = 应税基数 × 税率
  - 应付合计 = 应税基数 + 税额 + 运费
- 金额统一保留两位小数（四舍五入），避免浮点误差。

### 3. 浏览器打印 A4 结算单
- 点击右上角或汇总卡下方「打印结算单」按钮，或按 `Ctrl/Cmd + P`。
- 打印样式（`@media print`）会**自动隐藏录入控件、按钮与工具栏**，只输出结算单预览（表头 + 明细 + 汇总）。
- 建议在打印对话框中选择「A4」纸张、勾选「背景图形」（如需要保留边框）。

### 4. 导出 CSV
- 点击「导出 CSV」按钮，浏览器会下载 `FPC结算单_<单据编号>.csv`。
- CSV 包含：单据信息（编号、日期、税率、运费）、明细表（条目/单价/数量/小计）、汇总行（应税基数/税额/合计）。
- 文件带 UTF-8 BOM，可直接用 Excel 双击打开，中文不会乱码。

### 5. 草稿暂存（可选）
- 每次录入都会自动存入浏览器 `localStorage`（键名 `fpc_draft_v1`），关闭页面后再打开会自动恢复。
- 点击「清空」可清除全部明细与参数（含草稿），会弹出确认框。

## 税率修改方法

在左侧「结算参数」区域的「税率（%）」输入框中直接修改数字即可，例如改为 `0` 表示免税、`6` 表示低税率、`13` 为默认增值税率。修改后右侧合计会立即更新。

## 校验规则

- 单价或数量为空、非数字、或小于等于 0 时，该行标红并**不参与合计**，同时显示提示文字。
- 数量与单价做了非负与除零保护，税率/运费为负时按 0 处理。

## 计算示例（供核对）

| 场景 | 单价 | 数量 | 税率 | 小计 | 税额 | 合计 |
|------|------|------|------|------|------|------|
| 单行 | 5.00 | 100 | 13% | 500.00 | 65.00 | 565.00 |
| 免税 | 5.00 | 100 | 0% | 500.00 | 0.00 | 500.00 |

## 技术说明

- 单文件 `index.html`，内联 `<style>` 与 `<script>`（原生 JavaScript ES2020+）。
- 无任何外部 CDN、字体或图片依赖，完全离线可用。
- 图标使用内联 SVG（线性描边风格，无 emoji）。
- 颜色全部通过 `:root` CSS 变量定义，主色为沉稳蓝 `#2C6ED5`。
- 桌面端两栏布局（左录入 58% / 右汇总 42% 且 sticky），移动端自动单列堆叠。

## 已知限制

- 草稿仅存在于当前浏览器与当前域名（file:// 协议下各浏览器行为略有差异，部分浏览器在 `file://` 下可能禁用 `localStorage`，此时草稿功能自动失效但不影响其他功能）。
- 不支持多人协同与云端同步，适合单人快速结算。
- 打印排版以主流桌面浏览器为准，移动端浏览器打印建议先「导出 CSV」再在电脑上处理。
