# 本地一键复现速查

本文档帮助开发者在本地**快速、完整**地复现本仓库各子项目的运行环境。按子项目分区，按需取用即可；通用前置只需做一次。

> 安全提醒：不要将 `.env`、Cookie、API Key 等凭据提交入库（详见根 README「安全说明」与 `SECURITY.md`）。

---

## 0. 通用前置（所有子项目）

1. 安装 **Git** 与 **Python 3.13+**（建议用 `pyenv` 或系统包管理器，确认 `python --version`）。
2. 克隆仓库：
   ```bash
   git clone https://github.com/duyv0826/workbuddy-projects.git
   cd workbuddy-projects
   ```
3. 全程勿提交密钥；如需贡献，先阅读 `CONTRIBUTING.md` 与 `SOP-代码提交与开源发布流程.md`。

## 1. 动漫图片下载器 GUI

### 环境准备
- Python 3.13+；支持 PySide6 的操作系统（Windows / macOS / Linux）。

### 依赖安装
```bash
cd 动漫图片下载器GUI
pip install -r requirements.txt
# 核心依赖：PySide6==6.9.3、requests>=2.31、Pillow>=10.2
```

### 启动
```bash
python main.py
```

### 验证步骤
- **离线单测**（预期 27 项全 PASS）：
  ```bash
  python test_logic.py
  ```
- **仅校验 GUI 初始化**（无显示器环境）：
  ```bash
  QT_QPA_PLATFORM=offscreen python main.py
  ```
  窗口应正常构造、无 `NameError`/`ImportError`，退出码 0。
- **功能冒烟**：GUI 中选 Safebooru 源 → 关键词 `cat` → 数量 2 → 开始，应下载到本地目录。

## 3. Cline-DeepSeek 环境搭建

### 环境准备
- Python 3.10+（已验证 3.13）；**脚本仅用标准库，无需 `pip install`**。
- 网络需可达 `open.bigmodel.cn`。

### 配置密钥（`.env` 不入库，切勿提交）
```bash
cd Cline-DeepSeek环境搭建
# 直接新建 .env 并写入（仅本地，已被 .gitignore 忽略）：
#   ZHIPU_API_KEY=你的真实Key
#   ZHIPU_MODEL=glm-4.7-flash   # 可选，仅 verify_refactor.py 读取
```

### 运行
```bash
# 验证脚本：净化输出 STEP1-4 + 自动退避重试（429）+ 落盘 main_refactored.py
python verify_refactor.py

# 重构脚本：对源文件做模型重构
python run_refactor.py --source hello_world_project/main.py --output out.py
```

### 验证步骤
- `verify_refactor.py` 末尾打印 `[一致]`，且生成 `main_refactored.py`。
- 401/403：检查 `.env` 中 `ZHIPU_API_KEY` 是否正确、是否过期。
- 429：脚本自动按 6/12/24/48s 退避重试，无需手动干预。

## 常见问题

- **pip 安装慢**：换国内镜像 `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`。
- **PySide6 装不上**：确认 Python 版本与架构；Linux 需先装系统 Qt 依赖（如 `sudo apt install libgl1 libxkbcommon-x11-0`）。
- **Cline 脚本 401**：`.env` 中 `ZHIPU_API_KEY` 缺失或失效；重新获取智谱 API Key 后填写。
- **GUI 在无显示器服务器报错**：加 `QT_QPA_PLATFORM=offscreen` 仅做初始化校验。
- **转公开前**：先读根 README 顶部「私有仓库提示」；本仓库已不随附第三方样图（历史已清除），如自行添加媒体须为原创或已授权。
