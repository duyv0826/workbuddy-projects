# 动漫图片测试下载（样例复现指引）

本目录说明「动漫图片下载器 GUI」的**端到端实测方法**与**样例复现步骤**。它**不随附任何图片**——原先从公开图站抓取的第三方版权样图，已从本仓库的工作区与 git 历史中彻底清除，以避免在开源发布时外泄第三方版权内容。本目录仅作为「如何按需生成等价样例」的指引与佐证说明。

## 目录用途

- 记录下载器的「黄金验证路径」：确认 Safebooru 等源可正常抓取、图片可被 Pillow 全解码校验（无截断残件）。
- 便于协作者在不配置 Pixiv Cookie 的情况下，按本文档自行复现下载器的匿名全年龄源产出效果。
- 仓库自测 / 本地验证时，可对照新下载结果与本文档描述的预期（尺寸、格式、解码完整性）是否一致。

## 下载 / 重新生成方式

样例由「动漫图片下载器 GUI」在以下配置下产出，可随时复现：

1. 打开 `动漫图片下载器GUI/main.py`（详见该子目录 README 的安装与运行说明）。
2. 数据源选择 **Safebooru**（全年龄源，无需登录）。
3. 关键词填 `cat`，数量设为 2，选择本目录作为保存路径。
4. 点击「开始」即可重新生成等价的 SFW 样例。

如本地已具备 Python 环境，也可直接用下载器内部的 Safebooru 抓取逻辑批量拉取（命令/脚本以 `动漫图片下载器GUI` 为准，本目录不重复实现）。

## 常见问题

- **为什么目录里没有图片？** 为避免第三方版权内容随开源仓库分发，样图已从工作区与 git 历史清除；按「下载 / 重新生成方式」用下载器即可本地生成。
- **想用自己的样例？** 直接用下载器重新抓取即可，仓库不依赖任何特定图片；放入本目录前请确认为 SFW 且你有权分享。
- **图片显示损坏？** 若 JPEG 结尾无 `FFD9` 或无法用图片查看器打开，说明是截断残件，应丢弃并重新下载（下载器已内置 Pillow 全解码校验拦截此类文件）。
- **能否提交更多样例？** 可以，但请确保为 SFW 且你有权分享；大体积图片建议压缩后再入库，避免仓库膨胀。
