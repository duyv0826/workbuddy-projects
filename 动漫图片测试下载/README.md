# 动漫图片测试下载（样例目录）

本目录存放「动漫图片下载器 GUI」的**端到端实测样例产出**，用于对照验证下载链路（网络抓取 → 落盘 → 截断校验）是否正常。它不是独立可运行项目，而是下载器在真实数据源上跑通的佐证素材。

## 目录用途

- 作为下载器的「黄金样例」：确认 Safebooru 等源可正常抓取、图片可被 Pillow 全解码校验（无截断残件）。
- 便于协作者在不配置 Pixiv Cookie 的情况下，直接查看下载器在匿名全年龄源上的真实产出效果。
- 仓库 CI / 本地自测时，可对比新下载结果与既有样例的一致性（尺寸、格式、解码完整性）。

- 图片均为 JPEG 格式，经 Pillow `Image.open().load()` 全解码校验通过（确保不是截断残件）。

## 下载 / 重新生成方式

样例由「动漫图片下载器 GUI」在以下配置下产出，可随时复现：

1. 打开 `动漫图片下载器GUI/main.py`（详见该子目录 README 的安装与运行说明）。
2. 数据源选择 **Safebooru**（全年龄源，无需登录）。
3. 关键词填 `cat`，数量设为 2，选择本目录作为保存路径。
4. 点击「开始」即可重新生成等价的 SFW 样例。

如本地已具备 Python 环境，也可直接用下载器内部的 Safebooru 抓取逻辑批量拉取（命令/脚本以 `动漫图片下载器GUI` 为准，本目录不重复实现）。

## 常见问题

- **想换成自己的样例？** 直接删除本目录文件、用下载器重新抓取即可，仓库不依赖这些特定图片。
- **图片显示损坏？** 若 JPEG 结尾无 `FFD9` 或无法用图片查看器打开，说明是截断残件，应丢弃并重新下载（下载器已内置 Pillow 全解码校验拦截此类文件）。
- **能否提交更多样例？** 可以，但请确保为 SFW 且你有权分享；大体积图片建议压缩后再入库，避免仓库膨胀。
